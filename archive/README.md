# Archive

Historical material preserved for reference. Nothing in this directory is
loaded by the plugin or referenced by current documentation — do not extend it.

## Contents

- **`history/`** — process artifacts from the v3/v4 era: implementation plans,
  research packs, test reports, release notes (v4.0–v4.2), installation
  fix logs, the old `knowledge-core.md`, and assorted announcement drafts.
- **`R-and-D/`** — legacy agents, orchestration experiments, and design notes
  from earlier iterations of the project.
- **`integrations/`** — speculative framework integration templates
  (LangGraph et al.) from the v4 roadmap; never shipped.
- **`examples/`** — v2-era workflow examples.
- **`workflow-artifacts-2025-11-01/`** — outputs from a recorded workflow run.
- **`update-local-installation-v3.0-to-v3.1.sh`** — migration script from the
  deleted custom installer system (v5.0 replaced installers with the Claude
  Code plugin system).

For why v5.0 removed the installer suite and most of the machinery referenced
in these documents, see the `[5.0.0]` entry in the root `CHANGELOG.md`.
